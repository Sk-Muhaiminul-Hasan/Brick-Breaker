# 🎮 Brick Smasher

Welcome to **Brick Smasher**, a classic brick breaker-style game built using Java Swing!

This is my **first Java project**, created to learn the basics of Java, made with `JFrame`, `KeyListener`, `Timer`, and 2D graphics.

---

## 📌 Features

- Simple and clean gameplay mechanics.
- Control the paddle using keyboard keys.
- Break bricks by bouncing the ball.
- Window icon (game logo) included.
- Basic game score and game over detection.

## 🛠️ How to Run

1. **Clone or download the project.**
2. Open it in IntelliJ IDEA or your preferred Java IDE.
3. Make sure the `resources/` folder is marked as **Resources Root**.
4. Run `Main.java` — the game window should open.
